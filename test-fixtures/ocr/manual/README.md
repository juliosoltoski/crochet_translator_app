# Manual OCR Fixtures

This folder contains user-provided images for local OCR testing.

The sample magazine-layout image is useful for testing:

- Multi-column reading order.
- Small German crochet pattern text.
- Page curvature.
- Uneven lighting.
- Mixed text and product photography.

`daffodil-dorothy-1-column.jpg` is a simplified crop of the same material. It is useful for testing OCR quality when the reading-order problem is reduced but the photo still has rotation, soft focus, page shading, and dense crochet abbreviations.

Do not treat these files as app storage or user recipe history. They are test fixtures only. If copyright status is unclear, do not publish them in public distributions.
